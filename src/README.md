# Harley Freedom Riders Discord Bot

Discord Logs Bot untuk komunitas Harley Freedom Riders.

## 📦 Install

```bash
npm install
```

## ⚙️ Setup

Isi file `config.json`:

```json
{
  "token": "TOKEN_BOT",
  "clientId": "CLIENT_ID",
  "guildId": "GUILD_ID"
}
```

## 🚀 Register Slash Command

```bash
node deploy.js
```

## ▶️ Menjalankan Bot

```bash
node index.js
```

## 📜 Command

```bash
/logs
```

Fitur:
- Logs Join
- Logs Warn
- Logs Inactive
- Logs Promotion
- Logs Demotion
