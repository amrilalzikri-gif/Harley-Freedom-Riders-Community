# Harley Freedom Riders Logs Bot

## Install
```bash
npm install
```

## Deploy Slash Command
```bash
npm run deploy
```

## Start Bot
```bash
npm start
```

## IMPORTANT
Masukkan token bot Discord baru ke file `config.json`.

Jika token lama pernah dibagikan/public, segera regenerate token di Discord Developer Portal demi keamanan.
