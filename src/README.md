# Harley Freedom Riders - Discord Logs Bot

Bot Discord berbasis Python dengan pustaka `discord.py` untuk mengelola sistem pencatatan/log member (SSRP) secara semi-otomatis menggunakan Slash Command (`/logs`).

## Fitur
* Slash Command terintegrasi (`/logs`)
* Output mewah menggunakan Discord Embed & Banner Gambar
* Penanganan Error otomatis (Anti-Crash)
* Struktur rapi menggunakan Cogs System

## Cara Menjalankan Bot
1. Ekstrak file zip ini.
2. Install dependensi dengan perintah: `pip install -r requirements.txt`
3. Buka file `main.py` dan masukkan Token Discord Anda pada variabel `TOKEN`.
4. Jalankan bot: `python main.py`
